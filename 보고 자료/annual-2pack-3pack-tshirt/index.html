수량 구성

회의에서 결정할 것

1. 원단 발주 수량 확정

2PACK 30,000 SET / 3PACK 15,000 SET 기준으로 발주 진행 가능 여부 확인

2. 월별 가먼트 입고안 확정

예시: 1월 초 30% / 4월 초 50% / 6월 초 20% 또는 영업기획팀 희망안 회신

3. 패키지 디자인 투입 데드라인 확정

샘플 개발 리드타임 + 메인 생산 리드타임 기준으로 소싱팀 회신 필요

영업기획팀 요청

  • 연간 예상 수량 기준 원단 발주 진행 검토
  • 월별 파샬 입고 희망 수량/비율 회신

소싱팀 요청

  • 소재 퀄리티 및 원가 비딩 기준 최종 협력사 확인
  • 월별 분납 가능 여부 확인
  • 패키지 개발 투입 마감일 확인
  • 2PACK 기능성 표기 가능 여부 확인: COOL, 흡습속건, 접촉냉감

디자인실 요청

  • 소싱팀 데드라인 회신 후 패키지 디자인 개발 착수
  • 기존 패키지 재질 유지, 도안만 소폭 디벨롭

2PACK 변경안

  • 쿨코튼 원사 사용 내용 추가
  • 쿨 기능성 문구 표기 가능 여부 확인 필요
  • 소매 키키 포인트라벨 → 워드로고 포인트라벨 변경
  • 컬러: BK+BK / WH+WH / BK+WH

3PACK 변경안

  • 현재 도안 유지
  • 스티커 내 “MEN” 문구 삭제
작성: 어패럴 기획팀 변창현 / 이미지 미제공으로 패키지 이미지는 제외
