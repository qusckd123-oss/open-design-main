1. 스쿼드 TF 체계 소개 및 운영 방식

메인 목표 2가지 확정
  • ① 뉴베이직 재설계 — 유니섹스 라인을 여성 소비자도 함께 살 수 있는 방향으로 강화
  • ② IP(캐릭터) 활용 — 서브 트랙으로 운용, 콜라보·콘텐츠 형태로 노출 (상품 메인에 강제 삽입 X)
정기 운영 일정 확정

정기 미팅매주 월요일 동일 시간 진행

공유 채널매주 화요일 — 전날 미팅 내용 정리 후 공유 채널 업로드 (호진 과장 담당)

참석모두 필참 의무 아님. 초반에는 감독급이 일정 조율해 유연하게 운영

기타 운영 규칙
  • 복종 제한 없음 — 티셔츠 제안은 현실화하기 좋다는 이유의 권고, 구애받지 않고 자유롭게 제안 가능
  • 기본 제안 수량: 스타일당 약 200~300장. 설득력 있는 아이템은 1,000장 이상 상향 검토 가능
  • 신규 시도 아이템은 스쿼드 내부에서 기획·수량 결정 후 진행. 대물량은 사전 컨펌 필요
  • 로고·캐릭터 변형도 적극 제안 가능 (교묘한 변형 형태로 제안 → 피드백 수렴)
소재 담당 공석 대응

소재 담당 역할이 현재 공석. 임시로 스쿼드 전원이 함께 소재를 탐색하는 방식으로 운영. 월요일 미팅에서 정리해 공유.

시즌 적용 시기 확인 필요

사업부장님 면담 결과: 26FW부터 바로 적용하고 싶다면 바로 기획 진행. 27SS 이후도 무방. 스쿼드 내부에서 시즌 결정 가능.

2. 핵심 방향성 — 유니섹스의 여성화

위에서 내려온 방향 요약
  • 유니섹스가 너무 여성 라인(우먼스)과 양분화됨 → 유니 라인에 여성 소비자도 같이 살 이유를 만들어야
  • "여성스러운 디테일/컬러를 추가"가 아니라 → 여자도 편하게 입을 수 있는 베이직 유니 아이템 강화가 핵심
  • 우먼스는 러블리·프릴 위주 → 유니는 베이직·캐주얼로 차별화, 여성 고객 유입 경로 만들기

팀원별 의견 요약

강 대리 (소싱)
  • 원가 구조상 유니클로·어텐다드 대비 가격 경쟁력 낮음 → 컬러감·텍스처로 차별화
  • 레퍼런스: 자라 FW 워크자켓 — 기본 실루엣 + 포인트 컬러 구성 (베이직 컬러 1~2 + 포인트 컬러 전개)
  • 새 시도: 페이크레더 블레이저, 연조스웨이드 등 특종 아이템 업체 소싱 검토
순범 대리
  • 잘 팔렸던 그래픽 아이템(예: 하리보 ST16) — 한 시즌 후 죽이는 구조가 아쉬움
  • 검증된 아이템 리오더·컬러 추가로 대물량 전개, 그래픽은 유지하되 컬러를 늘리는 방식
  • 유쾌한 포인트의 스트릿 무드 유지 — 너무 세지 않게
배영 과장 (기획)
  • 유니 이슈화 너무 적음 — 마케팅에 SNS 트렌드 → 상품 반영 피드백 루프 요청
  • 남녀 함께 입는 연출을 컨텐츠에서 적극 노출해야 유니 구매 이유가 생김
  • 탄산마그네슘 레퍼런스 — 여성 타겟 모델 위주지만 남녀 모두 구매
동균 대리
  • 용품(모자 등) 접근 — 성별 구분 없는 유니 아이템으로 여성 라인과 브릿지 역할
  • 의류 그래픽과 연결된 모자 등으로 통일성·노출 효과 동시에
  • 여성 라인에서 별도 기획 중인 용품과 시너지 가능
지원 대리
  • 타겟: 20대 초중반 (중고생 포함) — 편하게 교복에 걸쳐 입을 수 있는 아이템
  • 레퍼런스: 후아유 — 데일리·교복 코디 가능 포지션
  • 커플템 연출 — 여성이 유니를 살 이유는 커플 구매. 원이 착장으로 남녀 함께 코디 노출
창현 대리
  • 브라운브레스처럼 댄스·음악 크루와 문화적 연결 — 크루 후원·협업으로 자연스러운 브랜딩
  • 스케이트/스트릿은 대표님 선호 아님. 크루화는 문화 차원에서 접근
지연 대리
  • 유니에서 잘 팔리는 아이템은 편한 데일리 착용 포지션
  • 여성이 유니를 고르는 이유 = 주로 커플템 → 커플 코디 연출로 바이럴 유도
  • 우먼스는 너무 러블리 → 러블리 싫어하는 여성 고객 흡수할 베이직+포인트 한 스푼 유니 필요
디자이너
  • 포인트 하나만 있는 심플 디자인 — 배색만으로도 충분히 차별화 가능
  • 레이어드 아이템 (예: 반팔+긴팔 소매 다른 소재, 컬러 동일) — 입기 편하면서 디테일 있음
  • 과한 컬러 배색보다 소재 다르게 + 컬러는 묻히게 하는 것이 트렌드
  • 키키 캐릭터 크게 넣으면 인플루언서 픽업 저조 → 타이포만이면 괜찮음

3. 벤치마크 브랜드

탄산마그네슘 톤세 테켓 웰빙 익스프레스 선러브 투어 브라운브레스 스컬프터 (참고) 골든션 차이
브랜드별 참고 포인트

탄산마그네슘여성 타겟 모델·광고 → 실제로 남녀 모두 구매. 동일 그래픽으로 라인 묶어 IP 활용. 우리가 가야 할 포지션의 레퍼런스

톤세빈티지 무드 컬러감. 아트워크+배색 조합이 시장 내 차별화 포인트. 컬러 트랙 레퍼런스

테켓컬러감 조합 레퍼런스 — 팀즈 채널에 사진 공유 요청

브라운브레스댄스·음악 크루와 문화적 연결이 브랜드 정체성. 크루화 접근 참고

웰빙 익스프레스 / 선러브 투어여성성 있는 유니섹스 포지션. 우리가 여성 소비자 흡수하려 할 때 참고 방향

스컬프터약간 세고 누나 감성. 그 강도보다는 낮게, 무드만 참고

4. 레퍼런스 아이템 & 제안 아이디어

검증된 과거 아이템 (재개발 후보)
  • ST16 (하리보 타이포폼 티셔츠) — 판매 좋음. 하리보 레퍼런스 → 스케치로 디벨로프 후에도 잘 팔림. 연계 상품(맨투맨·긴팔 등) 라인 확장 없이 끊긴 것이 아쉬움 → 이번에 전개 재고
  • 타이다이 원단 맥북돌이 티셔츠 — 잘 팔렸으나 원단 재고 소진. 타이다이 원단 확보 시 재기획 가능
  • 와플 후드 레이어드 롱슬리브 — 반응 좋음
  • 보라·노란 스트라이프 후드 니트 — 샘플 반응 좋음, 판매 아직 시작 전
  • 러닝코어 키키 그래픽 티 — 잘 팔렸음. 포인트 레이블 수준의 변형도 시도해볼 것
신규 아이템 제안 아이디어
  • 자라 FW 워크자켓 스타일 — 베이직 실루엣 + 포인트 컬러. 남녀 모두 무난, 컬러로 차별화
  • 페이크레더 블레이저 / 연조스웨이드 소재 아이템 — 기존에 없었던 특종 소재 업체 소싱 진행 예정 (강 대리)
  • 용품 — 모자류 — 남녀 구분 없는 진입 카테고리. 의류 그래픽과 연계 가능 (동균 대리)
  • 레이어드 아이템 — 소재 다른 반팔+긴팔 조합, 컬러는 묻히게. 입기 편하고 디테일 있음
  • 커플템 기획 아이템 — 남녀 함께 입는 연출 특화. 후드·롱슬리브 등 기본물로 가능
피트 재설계 제안

기존 오버핏/오피스핏 피트 히스토리 있음. 이번 기회에 피트 재설계(TF 블록 재설계) 논의 필요 가능성 제기. PD 합류 후 별도 논의 일정 잡기 [확인 필요]

5. 결정 — 2트랙 팀 편성

트랙 A — 검증 아이템 재개발
  • 기존 잘 팔렸던 아이템 발굴·재개발
  • 우먼스에서 잘 팔린 프린트 → 유니 라인 전개
  • 컬러 추가·라인 확장으로 연계 전개 (죽이지 않고 시즌 넘기기)
  • 기본 매출 확보 역할
트랙 B — 컬러감 신규 아이템
  • 톤세·탄산마그네슘 무드의 빈티지 컬러감 아이템
  • 배색·소재로 차별화하는 새 아이템 개발
  • 여성 소비자 흡수 포지션 공략
  • 신규 시도 트랙 (소량 테스트 → 검증 시 확대)
팀 편성 방법 확정
  • [호진 과장] — 임의로 팀 나눈 뒤 단체방 공유. 조정 원하는 멤버는 의견 제출하면 반영
  • 대략 트랙당 2명 내외로 편성 예정
  • IP(캐릭터) 활용 트랙은 별도로 두지 않고, 좋은 아이디어 생기면 다 함께 개발하는 방식

6. 마케팅 방향 요청 사항 ★

유니 이슈화 강화 요청 (배영 과장 → 마케팅)
  • 현재 모든 노출이 여성 모델 위주 → 유니 구매 이유 약해짐
  • 마케팅팀에서 SNS 트렌드 이슈 발생 시 스쿼드에 공유 → 빠르게 상품화 가능
  • 팀즈 채팅방에 이슈화될 만한 트렌드 편하게 공유해주면 상품에 반영
연출 방향 요청
  • 남녀 함께 입는 연출 — 커플템·데이트룩 등 실제 코디 노출로 유니 구매 이유 형성
  • 원이(리센느) 착장 활용 시 남녀 사이즈 함께 코디한 컷 적극 요청
  • 인플루언서 픽업: 20대 초중반 일반인급 인플루언서 (연예인 팬심 아닌, 코디 참고 목적 타겟)
